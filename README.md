# Secret Coder

## Overview

Secret Coder is a responsive programming academy website designed to showcase coding courses, instructors, student testimonials, and contact information. The project aims to provide an engaging landing experience for learners by combining modern design, animated content, and smooth navigation across course and instructor pages.

## Features

- Responsive multi-page website layout
- Course listing and details pages
- Instructor profile section
- Student testimonials carousel
- Contact and inquiry page
- Login and signup page templates

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Animate.css
- WOW.js
- Owl Carousel
- jQuery (required by Bootstrap components)

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Open the project folder in your preferred code editor.
4. Open `Index.html` in a web browser or run a simple local server.

## Usage

Use the website to explore the course offerings and instructor profiles. Navigate through the pages to view testimonials, contact information, and sample login/signup layouts. The project is intended as a frontend marketing site for a programming academy.
